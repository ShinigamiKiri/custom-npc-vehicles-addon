# Sound TODO List

The audio framework is fully implemented in the code, but you must manually provide the actual `.ogg` audio files. 

Please drop your sound files into the respective directories listed below. The exact filename must match what is written here.

1. **Gunfire**
   - File Path: `src/main/resources/assets/sbw_npc_addon/sounds/gunfire/rifle_shot_01.ogg`
   - Description: A standard rifle gunshot sound.

2. **Cannon**
   - File Path: `src/main/resources/assets/sbw_npc_addon/sounds/cannon/cannon_fire_01.ogg`
   - Description: A heavy cannon or tank firing sound.

3. **Bullet Flyby**
   - File Path: `src/main/resources/assets/sbw_npc_addon/sounds/bullet_flyby/bullet_flyby_01.ogg`
   - Description: The whizzing sound of a bullet flying past the player.

4. **Bullet Impact**
   - File Path: `src/main/resources/assets/sbw_npc_addon/sounds/bullet_impact/bullet_impact_01.ogg`
   - Description: The sound of a bullet striking a surface or dirt.

### Where to find sounds
You can source free, high-quality audio files from:
- [Freesound](https://freesound.org/)
- [OpenGameArt](https://opengameart.org/)

Once the `.ogg` files are placed at these exact paths, the sounds will automatically be loaded and work in-game!
